# 🚀 Torrent- v1.1 (GUI)

**Полноценный графический торрент-клиент** — больше никаких командной строки!

## ✨ Что нового в v1.1
- Красивый современный **GUI** на CustomTkinter
- Прогресс-бар, скорость, пиры в реальном времени
- Выбор файла .torrent из папки
- Вставка magnet из буфера обмена
- Тёмная тема (modern look)

## 👨‍💻 Запуск

```bash
git clone https://github.com/nkey26005/Torrent-.git
cd Torrent-

pip install customtkinter
python gui.py
```

## 🚀 Как пользоваться
1. Вставьте magnet-ссылку или нажмите "📁 .torrent"
2. Выберите папку сохранения
3. Нажмите кнопку **"▶️ Начать загрузку"**

Всё! Красивый прогресс и статистика в реальном времени.
